#Diplom_2
# Дипломный проект. Часть 2 — API-тесты для Stellar Burgers

## 📋 Описание проекта
Проект содержит автоматизированные тесты для проверки API учебного сервиса [Stellar Burgers](https://stellarburgers.education-services.ru).  
Тесты покрывают основные сценарии работы с пользователями и заказами.

## 🚀 Стек технологий
- **Java 11** — язык программирования
- **Maven** — сборка проекта и управление зависимостями
- **JUnit 4** — тестовый фреймворк
- **REST Assured** — тестирование API
- **Allure** — отчёты о тестировании
- **Jackson** — работа с JSON
- **JavaFaker** — генерация тестовых данных

## ✅ Что тестируется
### Пользователи (`/api/auth`)
- ✅ Создание пользователя
- ✅ Логин пользователя
- ✅ Изменение данных пользователя
- ✅ Негативные сценарии (неверные данные, существующий пользователь)

### Заказы (`/api/orders`)
- ✅ Создание заказа с авторизацией
- ✅ Создание заказа без авторизации
- ✅ Получение списка ингредиентов
- ✅ Негативные сценарии (пустой список, неверный хеш)

## 🛠 Как запустить тесты
1. Склонировать репозиторий:

git clone https://github.com/lidiagermogenova/Diplom_2/tree/develop2

2. Перейти в папку проекта:

cd Diplom_2

3. Запустить тесты:

mvn clean test

4. Сгенерировать Allure-отчёт и открыть в браузере:

mvn allure:serve
